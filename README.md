# TOWV Limited Financial Forecast Model | 5-Year Funding & Scenario Analysis

This repository contains a professional financial forecasting model for TOWV Bootcamp Limited, a U.S.-based distributor. The model was built to support funding analysis, business planning, scenario testing, and financial performance review over a 5-year forecast period.

The workbook follows a structured financial modeling approach, with dedicated sections for model guidance, assumptions, scenario analysis, calculations, financial statements, cash flow forecasting, and ratio analysis.

## Model Highlights

- 5-year financial forecast model
- Built for funding and business planning purposes
- Scenario and sensitivity analysis
- Revenue, cost, operating expense, and margin forecasting
- Loan financing and repayment schedule
- Profit and loss statement forecast
- Balance sheet forecast
- Cash flow statement forecast
- Free Cash Flow to Firm analysis
- Financial ratio and performance analysis
- Summary dashboard for key outputs
- Model guide with cell-style explanations and workbook structure

This project was created as a financial modeling portfolio piece to demonstrate practical skills in:

- Financial forecasting
- Business planning
- Funding analysis
- Scenario modeling
- Integrated financial statement modeling
- Cash flow analysis
- Financial ratio analysis
- Excel and Google Sheets model structuring

## Use Case

This model can be used to evaluate the financial outlook of a distribution business seeking funding. It helps users understand projected profitability, funding requirements, debt repayment capacity, cash flow performance, and key financial metrics under different operating scenarios.
